# profile-app-practice

## 概要

COACHTECH 教材 Tutorial 9-1「Laravel基礎ハンズオン」で作成した成果物です。

Laravelの基礎を使い自己紹介ページを作成しました。

## 使用技術

- PHP 8.x
- Laravel 10.x
- Blade テンプレート

## 学んだこと

- ルーティング→コントローラー→ビューの基本フロー
- Bladeテンプレートでの変数表示とループ
- コントローラーからビューのデータの受け渡し

## 動作確認

Dockerを起動する。
http://localhost/profile にアクセスする。
